## Configuration

| Variable / Key | Location | Purpose | Required |
|----------------|---------|---------|---------|
| `GOOGLE_API_KEY` | Environment variable | Google Gemini API authentication | Yes |
| `ELEVENLABS_API_KEY` | Environment variable | ElevenLabs TTS API authentication | If ElevenLabs TTS used |
| `gemini_model` | `user_profile` table / `config.yaml` | Which Gemini model (default: `gemini-1.5-flash`) | No |
| `tts_engine` | `user_profile` table | TTS provider: `pyttsx3` / `elevenlabs` / `coqui` | Yes |
| `stt_model` | `user_profile` table | Whisper model size (default: `whisper-base`) | Yes |
| `wake_word` | `user_profile` table | Primary activation phrase (default: `Hey Zeno`) | Yes |
| `working_hours_start/end` | `user_profile` table | Working hour boundaries for scheduling | Yes |
| `timezone` | `user_profile` table | User timezone for date resolution | Yes |
| `workspaces.yaml` | `~/Zeno/workspaces.yaml` | Workspace macro definitions (YAML) | No (optional workspaces) |
| `config.yaml` | `~/Zeno/config.yaml` | Human-editable config file (mirrors `user_profile`) | No (DB is source of truth) |
